# 灵活的 run 命令输入方式

## ✅ 功能已实现

`run` 命令现在支持多种灵活的输入格式，不再需要一个个手动输入行号。

## 🎯 支持的格式

### 1. **单个任务**
```bash
run 4              # 只跑第 4 行
```

### 2. **多个任务（逗号分隔）**
```bash
run 4,5,6          # 跑第 4、5、6 行
run 1,3,5,7        # 跑第 1、3、5、7 行
```

### 3. **范围（推荐）⭐**
```bash
run 1-4            # 跑第 1、2、3、4 行
run 10-15          # 跑第 10 到 15 行
```

### 4. **混合格式（最灵活）⭐**
```bash
run 1-4,6-9        # 跑第 1-4 行和第 6-9 行
run 1-3,5,7-9      # 跑第 1-3 行、第 5 行、第 7-9 行
run 5,10-12,15     # 跑第 5 行、第 10-12 行、第 15 行
```

### 5. **中文逗号支持**
```bash
run 1-4，6-9       # 支持中文逗号（自动转换）
```

## 📝 使用示例

### 示例 1: 批量提交连续任务

之前需要输入：
```bash
run 1
run 2
run 3
run 4
```

现在只需一条命令：
```bash
run 1-4
```

### 示例 2: 跳过某些行

想跑第 1-4 行和第 6-9 行（跳过第 5 行）：
```bash
run 1-4,6-9
```

### 示例 3: 复杂组合

想跑第 1-3 行、第 5 行、第 7-9 行：
```bash
run 1-3,5,7-9
```

## 💡 智能处理

### 1. **自动去重**
```bash
run 1-5,3-7    # 自动去重为 [1,2,3,4,5,6,7]
```

### 2. **自动排序**
```bash
run 5,2,3-4    # 自动排序为 [2,3,4,5]
```

### 3. **越界检查**
如果 Excel 只有 10 行：
```bash
run 1-15
[跳过] 第 11 行越界（总共 10 行）
[跳过] 第 12 行越界（总共 10 行）
...
```

### 4. **空提示词检查**
自动跳过没有提示词的行：
```bash
run 1-5
[跳过] 第 3 行提示词为空
完成：4 个，跳过：1 个
```

### 5. **无效格式处理**
```bash
run 1-4,abc,6-9
[跳过] 无效格式：abc
```

## 🆚 对比

| 操作 | 之前 | 现在 |
|------|------|------|
| 跑 10 个连续任务 | 输入 10 次 `run N` | 输入 1 次 `run 1-10` |
| 跑分散的任务 | 输入多次 `run N` | 输入 1 次 `run 1,3,5,7,9` |
