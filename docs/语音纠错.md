# 语音纠错（领域词库 + DeepSeek 语义纠错）

Whisper 是「听音写字」，同音字（钙片/盖片、骨密度/股民度）它无从分辨——模型再大也难免。
本功能用两招把中文口播逐字稿改准：

1. **领域词库**（一份两用）：实时识别时喂 Whisper 的 `initial_prompt`，让「听」这遍就少写错；
   纠错时作为「这些词的正确写法」清单送进大模型 prompt。
2. **识别后大模型语义纠错**：把整篇逐字稿发给一个 OpenAI 兼容的 chat 端点（默认 DeepSeek），
   让大模型按上下文**只改错别字/同音字/明显断句**，**保持每行编号与行数不变**——
   于是句子时间戳原样保留，纠错后仍能拿去烧字幕。

> 一句话：词库治「听」的偏差，DeepSeek 治「写」的偏差；二者共用同一份词库。

## 🖥 在哪里配置（统一收口到「接口管理」页）

所有语音相关配置都在 **🔌 接口管理** 页维护（该页默认藏起来：在「⚙️ 设置」按维护口令
`Alt+W` / Mac `⌘+W` 验证通过，左侧导航才出现并跳进去）。页顶是一屏**配置检查清单**，逐行 ✅/⚠
覆盖：线路数 / 机器翻译 / 素材提取接口 / 任务表 Excel / **Whisper 各档就绪** / **豆包 Vision** /
**DeepSeek 纠错** / **词库条数**，旁边「🔄 重新检查」随时刷新。

> 整页套了滚动区（与设置页同款）：卡片多、内容比屏幕高时可上下滚动，不会再把下面的「语音纠错 / 词库」卡裁掉。

下方三块卡片（**保存即生效、不用重启**，区别于线路/翻译那类要「💾 保存部署」后重启的）：

| 卡片 | 作用 | 存到哪 |
|------|------|--------|
| 🎙 语音模型（Whisper） | tiny/base/small/medium 就绪状态 + 逐档「⬇ 下载」（可勾国内镜像，大文件走直链续传有真实进度）+ 打开模型目录 | 模型目录（`%APPDATA%\AIGC视频助手\models`） |
| 🧠 豆包 Vision | api_key（密文落盘）/ 端点 ID / Base URL + 💾 保存 | `config.json` 的 `doubao_vision` 段 |
| ✨ 语音纠错（DeepSeek） | api_key（密文落盘）/ 模型名（默认 `deepseek-chat`）/ Base URL + 💾 保存 + 🌐 测试；下方**领域词库**：一行一词直接编辑，也可 📥 从 Excel/CSV/JSON 导入、📤 导出为文件 + 💾 保存词库 | `config.json` 的 `asr_fix` / `asr_glossary` 段 |

> 领域词库支持三种文件格式维护（词多时比在文本框里一行行敲省事）：
> - **Excel(.xlsx/.xls) / CSV**：整表逐格取非空值——单列清单＝逐行一个词，多列也一并收下；CSV 自动试 UTF-8/GBK；
> - **JSON**：递归取所有字符串叶子（`["钙片",…]`、`[{"词":"钙片"}]`、`{"terms":[…]}` 都吃）；
> - 导入后**先合并去重填进文本框供审阅**，不自动落盘；确认无误再点「💾 保存词库」才生效。导出则不带表头（纯逐行一词），避免往返时把表头当成词。

> 原来散在「爆款拆解 / 字幕」面板里的**模型下载、豆包配置**都已挪到这里统一维护；
> 那两个面板只留「用哪档模型」下拉与就绪状态，缺什么时点「去接口管理配置 / 去下载模型」跳回本页。

**密钥安全**：豆包 / DeepSeek 的 `api_key` 都以**你的姓名为密钥**加密写进 `config.json`，
盘上不留明文；换了姓名解不开即按未配置处理。输入框留空＝不改动已存密文。

## 🗣 实时识别 + ✨ 纠错（播放器「🎤 识别字幕」浮窗）

播放器顶栏点「🎤 识别字幕」弹一个无边框、总在最前的浮窗，后台流式转写、逐句上屏。

- **起识别时**：若词库非空，自动把 `领域词库` 拼成 `initial_prompt` 喂给 Whisper，
  让实时这遍就少写同音字（状态栏会提示「已带 N 个词库词」）。
- **识别完成后**：标题栏的 **✨ 纠错** 按钮亮起，点它后台起一个线程把整篇逐字稿送 DeepSeek 纠错：
  - 成功：文本框按 `[mm:ss] 纠正文` 逐行重写，**时间戳与原句一一对应、句数不变**，只换了字。
  - 失败 / 未配置：状态栏红字提示，**绝不静默、绝不改坏原文**（原文一个字不动，可重试）。

- 纠错不再只活在浮窗里：工具中心「🎙 语音识别」与「🔥 爆款拆解」面板都放了 **✨ DeepSeek 语义纠错**
  勾选（共用 `gui.asr_widgets.FixToggle`）：未配置时选项置灰 + tooltip 说明去哪儿配，**不弹窗、不拦路**；
  勾上则识别完成后调 `apply_fix` 把逐字稿送 DeepSeek 改同音字（拆解里为显式 opt-in，默认关）。

## 🔬 纠错怎么保证不吞句、不错位（`correct_segments`）

1. 整篇（或按 ≤40 行一块）拼成「**编号行**」：`1\t<文本>\n2\t<文本>…` 发给模型；
   system prompt 死命令：只改错别字/同音字/断句，**保持每行编号与行数完全一致**、不翻译、不改写风格；
   词库非空时附一句「以下词是正确写法」清单。
2. 回来后按**行首编号**映射回填到原段：
   - 编号 / 行数对得上 → 用纠正文本；
   - 某行编号越界、丢失、解析成空 → **该行回退原文**，绝不吞段或错位；
   - 整块请求失败（限流重试耗尽、返回异常）→ **整块保留原文**，其它块照常。
3. 返回一个与入参**等长**的文本列表；时间戳始终由调用方原样保留（纠错只碰文本，不碰结构）。

## ⚙️ 默认参数

- DeepSeek：`base_url=https://api.deepseek.com/v1`、`model=deepseek-chat`（可改成任意 OpenAI 兼容端点）。
- 豆包 Base URL：`https://ark.cn-beijing.volces.com/api/v3`。
- 面板「用哪档模型」默认取**已就绪的最佳档**（`best_ready_size`），不再写死未下载的 `medium`
  ——避免一进面板就催你下载。

## 🗂 代码结构

```
core/config.py                          asr_fix 段读写 + asr_glossary 词库读写（加解密与豆包同款）
                                        + glossary_from_file/glossary_to_file：词库 Excel/CSV/JSON 导入导出（pandas 懒引入）
video_text_tools/asr/transcribe.py       transcribe_stream(..., initial_prompt=None) 透传给 whisper
video_text_tools/asr/fixer.py           AsrFixer.correct_segments：编号行发、按编号回填、失败退原文；
                                        apply_fix(segments, glossary, cfg, chunk)→(changed,cost,note) 统一入口（绝不抛）
gui/asr_live.py                         浮窗：词库喂 initial_prompt + 识别完成后 ✨ 纠错（_FixWorker 后台）
gui/asr_widgets.py                      ModelBar（模型下拉+就绪+就地下载）/ FixToggle（纠错勾选，未配置置灰 tooltip、不弹窗）
gui/pages_api.py                        配置检查清单 + Whisper/豆包/DeepSeek/词库 三卡（保存即生效）；整页套 QScrollArea 可滚；词库导入/导出
gui/dialogs_asr.py                      工具中心「🎙 语音识别」：转写→TXT/SRT/烧录 + 纠错开关（走 subtitle 引擎）
gui/dialogs_breakdown.py / dialogs_subtitle.py  模型下拉+✨纠错勾选；缺依赖时才给引导，不弹教学框
```

> 语音识别已从原来散在 `breakdown/` 里的实现抽成**主体包** `video_text_tools/asr/`（types/transcribe/fixer）；
> `breakdown/models.py` 只做 re-export，异常/类型与 asr 是同一批对象。纠错调用统一走 `apply_fix`。
