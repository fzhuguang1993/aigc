# 视频时长模式切换功能

## ✅ 功能已实现

支持两种视频时长模式：**5 秒模式** 和 **15 秒模式**，运行时可动态切换。

## 🎯 主要特性

### 1. **时长模式切换**

通过控制台命令随时切换视频时长：

```bash
duration 5        # 切换到 5 秒模式
duration 15       # 切换到 15 秒模式
```

### 2. **口播文案智能提取**

- **5 秒模式**: 不提取口播文案（视频太短）
- **15 秒模式**: 自动提取口播文案

### 3. **默认配置**

- 默认使用 **5 秒模式**
- 最小口播提取时长：**10 秒**

## 📝 使用方法

### 启动程序

```bash
python main.py
```

启动后会显示当前模式：
```
================================================================================
交互式控制台已启动
================================================================================
命令：
  ...
  duration 5        切换到 5 秒模式
  duration 15       切换到 15 秒模式
  当前模式：5 秒
  q / quit          退出
================================================================================
```

### 切换模式

在控制台中输入：

```bash
> duration 15
[INFO] 已切换到 15 秒模式
```

或切换回 5 秒：

```bash
> duration 5
[INFO] 已切换到 5 秒模式
```

### 提交任务

切换模式后，提交的新任务会使用新的时长：

```bash
> run new
   第 34 行提交成功 [acc1]    # 使用当前模式的时长
   第 35 行提交成功 [acc2]    # 使用当前模式的时长
```

## 🔧 配置说明

### 核心配置 (`core/config.py`)

```python
# 默认视频时长（秒）
DEFAULT_DURATION = 5

# 脚本提取配置
EXTRACT_SCRIPT_ENABLED = True      # 是否启用口播提取
MIN_DURATION_FOR_SCRIPT = 10       # 最小提取时长（秒）
```

### 工作原理

1. **提交任务时**: 使用 `DEFAULT_DURATION` 作为视频时长
2. **提取口播时**: 
   - 如果 `DEFAULT_DURATION < MIN_DURATION_FOR_SCRIPT` (即 5 秒)，不提取
   - 如果 `DEFAULT_DURATION >= MIN_DURATION_FOR_SCRIPT` (即 15 秒)，提取

## 📊 模式对比

| 特性 | 5 秒模式 | 15 秒模式 |
|------|---------|----------|
| 视频时长 | 5 秒 | 15 秒 |
| 口播提取 | ❌ 不提取 | ✅ 自动提取 |
| 适用场景 | 空镜、产品展示 | 口播、讲解类 |
| 生成速度 | 快 | 较慢 |
| 文件大小 | 小 | 大 |

## 💡 使用建议

### 场景 1: 纯产品展示（空镜）

使用 **5 秒模式**：
```bash
> duration 5
> run new
```

优势：
- 生成速度快
- 文件体积小
- 不需要口播文案

### 场景 2: 产品讲解（有人物口播）

使用 **15 秒模式**：
```bash
> duration 15
> run new
```

优势：
- 可以提取口播文案
- 适合讲解类内容
- 信息量更大

### 场景 3: 混合使用

根据需求灵活切换：
```bash
# 先跑一批空镜
> duration 5
> run 1,2,3

# 再跑一批口播
> duration 15
> run 4,5,6
```

## ⚙️ 技术细节

### 时长参数传递

1. **main.py**: 定义全局变量 `current_duration`
2. **submit.py**: 提交时使用 `DEFAULT_DURATION`
3. **script_extractor.py**: 根据时长决定是否提取

### 口播提取逻辑

```python
# 伪代码
if EXTRACT_SCRIPT_ENABLED and DEFAULT_DURATION >= MIN_DURATION_FOR_SCRIPT:
    提取口播文案
else:
    静默跳过（不输出警告）
```

## 📁 修改文件

1. **`core/config.py`**
   - 添加 `DEFAULT_DURATION` 配置
   - 添加 `EXTRACT_SCRIPT_ENABLED` 开关
   - 添加 `MIN_DURATION_FOR_SCRIPT` 阈值

2. **`main.py`**
   - 添加 `current_duration` 全局变量
   - 显示当前模式

3. **`console/app.py`**
   - 添加 `duration` 命令
   - 显示当前模式提示

4. **`workers/submit.py`**
   - 使用 `DEFAULT_DURATION` 作为视频时长

5. **`processors/script_extractor.py`**
   - 根据时长判断是否提取口播
