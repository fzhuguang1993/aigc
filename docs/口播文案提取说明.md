# 口播文案提取功能说明

## ✅ 功能已实现

从 AI 视频生成提示词中自动提取中文口播对话，并写入 Excel 的"口播文案"列。

## 🎯 工作原理

### 1. 提取规则

系统会自动识别以下格式的对话内容：

- **格式 1**: `<d>[Chinese] ... </d>` - 主要提取方式
- **格式 2**: `说...: "..."` - 备用提取方式

### 2. 处理流程

```
用户填写提示词 → 提交任务 → 自动提取口播 → 回写 Excel
```

### 3. 示例

**原始提示词片段：**
```
[Shot 1] ... He says: <d>[Chinese] 最近这肚子老是胀，吃啥都不消化，上厕所也费劲。</d>
[Shot 2] ... She says: <d>[Chinese] 你这是肠胃不好。现在厂家国庆大促，一百多块钱，整整一百袋！</d>
```

**提取后的口播文案：**
```
最近这肚子老是胀，吃啥都不消化，上厕所也费劲。
你这是肠胃不好。现在厂家国庆大促，一百多块钱，整整一百袋！
一百多块钱一百袋？那够吃小半年了吧？
对，一百袋，趁活动赶紧买，过几天就恢复原价了！
```

## 🔧 技术实现

### 核心代码位置

- **提取逻辑**: `processors/script_extractor.py`
  - `extract_script_from_prompt()` - 正则表达式提取
  - `ScriptExtractor.extract()` - 主提取方法（带缓存）
  
- **Excel 写入**: `utils/excel_utils.py`
  - `update_row()` - 自动处理多行文本（换行→空格）

### 性能优化

- ✅ **缓存机制**: 相同提示词只提取一次
- ✅ **本地处理**: 无需调用外部 API，速度快
- ✅ **错误容错**: 提取失败不影响任务提交

## 🎮 使用方式

### 自动提取（推荐）

提交任务时自动提取：
```bash
run 4              # 跑第 4 行，自动提取口播
run new            # 扫描并跑所有新项目，自动提取
```

### 手动提取

单独提取某行的口播：
```python
# 在 Python 环境中运行
from processors.script_extractor import ScriptExtractor
from core.logger import Ctx

extractor = ScriptExtractor("http://localhost")
success = extractor.extract_and_save(
    row_idx=3,           # 第 4 行（从 0 开始）
    prompt="你的提示词...",
    account_base="http://acc1.api",
    ctx=Ctx(row=3)
)
```

## 📝 Excel 列说明

写入列：**脚本** (D 列)

- **来源**: 从"提示词"列自动提取
- **格式**: 每句对话用空格分隔（多行文本自动转换）
- **用途**: 用于视频配音、字幕生成等后续处理

## ⚙️ 配置说明

无需额外配置，功能默认启用。

如需调整提取规则，可修改 `processors/script_extractor.py` 中的正则表达式：

```python
# 主要格式：<d>[Chinese] ... </d>
pattern1 = r'<d>\[Chinese\]\s*(.*?)\s*</d>'

# 备用格式：说...: "..."
pattern2 = r'说.*?:\s*["\'](.+?)["\']'
```
