# 项目目录介绍

> AIGC 视频生成辅助系统 —— 全仓库目录 / 模块职责与依赖关系说明。
> 面向对象：接手维护的同事（含无编程基础者）。读这一篇即可定位「某个功能在哪个文件、
> 改动会波及哪些层」。
>
> 最后更新：随「耦合整理」一并校准（新增 `gui/tools_registry.py`、`gui/dialogs_product.py`）。

---

## 一、整体分层与依赖方向

系统是一个 **PySide6 桌面客户端 + 一个可选的 FastAPI 网关服务端** 的组合。客户端按
「越靠下越纯净」的原则分层，**依赖只允许自上而下流动**，反向 import 视为架构违规：

```
        ┌─────────────────────────────────────────────┐
入口层   │  main.py（命令行/控制台）   desktop.py（GUI）  │
        └───────────────┬─────────────────────────────┘
                        ▼
        ┌─────────────────────────────────────────────┐
表现层   │  gui/   全部界面：主窗口、各页面、对话框、组件底座 │  ← 唯一可 import Qt 的层
        │        （widgets/dialogs 之外，gui 不被任何下层引用）│
        └───────────────┬─────────────────────────────┘
                        ▼
        ┌──────────────────────────┐   ┌────────────────┐
业务层   │  workers/  提交·轮询·扫描   │   │  processors/    │  归档·审片·文案·下载
        └───────────────┬──────────┘   └───────┬────────┘
                        ▼                       ▼
        ┌─────────────────────────────────────────────┐
领域/数据│  store/  各 *_store 领域库 + db.py（SQLite）    │
        └───────────────┬─────────────────────────────┘
                        ▼
        ┌─────────────────────────────────────────────┐
基础层   │  core/  配置·路径·命名·HTTP·日志·词库·授权·翻译   │
        │  registry/ 任务注册·账号状态·负载均衡            │
        │  utils/  Excel 读写·跨平台桌面动作               │
        │  video_text_tools/  纯功能工具包（回调式、无 Qt）  │
        └─────────────────────────────────────────────┘

        server/  独立网关（卡密激活 + 请求转发 + 限流），与客户端零互依赖
```

**几条硬约定（改动前务必遵守）**
- `gui` 是表现层，**下层（core/store/workers/processors）绝不能 import gui**；Qt 也只应出现在 `gui`（唯一例外：`core/special.py` 的特供版弹窗，属刻意收口、可整体移除）。
- 上层不直接摸 `store.db` / `sqlite3`，一律走对应领域的 `*_store` 封装。
- `video_text_tools` 是纯功能包（业务逻辑、无界面），`gui/tool_panels.py` 只做 UI 并回调它。
- `server/` 自带一份 `store.py`（服务端 SQLite），与客户端 `store/db.py` **各管各的库、互不引用**；服务端表结构演进不会自动同步到客户端。

## 二、入口与运行方式

| 文件 | 作用 |
|---|---|
| `main.py` | 主入口，命令行 / 控制台模式（数据源与 GUI 共用 SQLite）。 |
| `desktop.py` | Windows 桌面版 GUI 入口，装载 `gui.main_window.MainWindow`。 |
| `build.bat` | PyInstaller 打包脚本（`assets/app.ico` 为图标）。 |
| `requirements.txt` | 运行时依赖：pandas、openpyxl、requests、volcengine、PySide6、cryptography。 |
| `requirements-dev.txt` | 开发/测试依赖（叠加 `pytest`），分发不需要。 |
| `pytest.ini` | 测试配置：`testpaths = tests`，用例文件命名 `test_*.py`。 |
| `config.json` | 运行期配置（GUI 设置页读写）。 |

- 运行时目录（SQLite / 日志 / 输出）由环境变量 `AIGC_HOME` 锚定；凭证配置家由 `AIGC_CONFIG_DIR` 锚定。测试会临时改写这两个变量做隔离（见 `tests/conftest.py`）。
- 敏感配置放在 `core/config_local.py`（被 `.gitignore` 忽略），模板为 `core/config_local.example.py`；**本地配置优先级高于打包内置**。

## 三、逐目录说明

| `setup_wizard.py` / `first_run(gui)` | 首次运行配置向导，生成 config.json。 |
| `naming.py` | 成品文件命名规则（可在设置页自定义 token 组合）。 |
| `api_client.py` | HTTP 请求封装，统一异常约定。 |
| `license.py` | 商用激活体系：卡密激活 / 机器码 / 令牌缓存 / 防离线滥用。 |

### 3.3 `registry/` —— 运行时状态
- `manager.py`：任务注册 + 账号状态 + 负载均衡（`REG` 单例，多线路轮转的核心）。

### 3.4 `workers/` —— 后台执行链路
| 模块 | 职责 |

### 3.5 `processors/` —— 产物后处理

|---|---|

## 四、关键数据流（帮助定位改动面）

1. **建任务 → 出片 → 审片 → 归档**
   `pages_tasks` 录入 → `task_store`（SQLite）→ `workers/submit`（经 `registry` 负载均衡、`api_client`/`server` 网关）→ `workers/poll` 拉状态 → `processors/video_processor` 下载并按 `core/naming` 落 `outputs/` → `pages_output_lib` 审片（`processors/output_mark` 标可用/不可用）→ 「批量归档」`processors/archiver` 只搬「可用」进成品库或素材库。
2. **筛选口径**：列表 / 「更多筛选」的日期区间统一用 `kit.DateRangePicker`，避免各页各写一套。
3. **配置读写**：GUI 设置页 → `config.json`；打包内置值被 `config_local.py` 覆盖；迁移走 `core/config_package`。
4. **tooltip / 圆角浮层**：全站由 `gui/kit.py` 的 `TipBubble` + `_TipRouter` 在 `theme.apply_theme` 时接管，业务侧只需 `setToolTip(...)`。
