### 使用方法

#### 方法 1: dd 呼出菜单
```bash
> dd
============================================================
【功能菜单】
============================================================
1. 查看活跃任务
2. 查看账号健康
3. 扫描新项目
4. 取消任务
5. 跑单行 (输入行号)
6. 跑多行 (输入行号，逗号分隔)
7. 跑范围 (输入 1-10)
8. 跑所有新项
9. 切换时长模式
0. 继续运行
============================================================
```

#### 方法 2: 数字快捷键
直接输入数字即可执行对应操作：

```bash
> 1              # 查看活跃任务
> 2              # 查看账号健康
> 3              # 扫描新项目
> 4              # 取消任务
> 5              # 跑单行
> 6              # 跑多行
> 7              # 跑范围
> 8              # 跑所有新项
> 9              # 切换时长模式
> 0              # 继续运行
> q              # 退出
```

## 🎯 使用建议

### 日常使用

**推荐流程：**
1. 启动程序，看汇总信息
2. 输入 `7` → 输入 `1-20` → 批量提交
3. 输入 `1` → 查看进度
4. 输入 `0` → 继续运行

### 快速操作

- **1**: 看任务
- **2**: 看健康
- **3**: 扫新项
- **7**: 跑范围
- **q**: 退出

### Vim 风格

- 按 `dd` 呼出菜单（类似 Vim 的删除行）
- 按数字选择功能
- 按 `0` 返回继续运行
