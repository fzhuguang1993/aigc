# 新用户指南 —— 功能与接口速览

> 面向对象：第一次拿到本软件、不需要懂编程的同事。
> 读这一篇就能明白：**每个功能是干什么的**、**软件背后用到了哪些接口、各接口负责什么**，
> 以及作为一个普通用户，你到底需要动哪些、不需要动哪些。

---

## 〇、一句话认识这个软件

这是一个 **批量 AI 短视频创作与素材管理工具**：你在任务表里填好提示词，软件自动提交到
云端 GPU 服务生成视频，生成完自动下载、按规则重命名存到本地；同时还提供产品中心、
素材库/成品库、爆款拆解、录屏、语音识别、一键发布等一整套配套能力。

日常使用**只需要填一个姓名**——所有接口地址都由维护人提前内置在软件里，你不用配置任何地址。

## 一、有哪些功能（按软件里的板块划分）

软件左侧导航分成四大可安装板块 + 几个常驻页。装的时候勾了哪些板块，就露出对应入口。

### 1. 🖥️ 数据中台（dashboard）
- **干什么**：把你跑过的所有任务、产出做成 BI 看板——执行量、成功/失败/取消、成功率、
  平均生成时长等指标卡，加每日趋势、状态占比、产品分布、时长分布、线路分布等多张图表。
- **能下钻**：点图上某一段/某根柱子，弹窗看这一批的明细；右上角切「今日 / 近 7 / 14 /
  30 / 90 天 / 全部（累计）」。
- **进度汇报**：页面底部有「📋 今日进度汇报」卡，点「复制汇报」就能把当天数据原文粘到
  微信/飞书群，自动带上你的姓名。
- **执行记录**也在这一页（点页头「🕘 查看执行记录」）：每次提交尝试都留一行，可搜索、
  筛选、导出 Excel。

### 2. 🎯 AIGC 板块 + 素材库（aigc）
- **任务中心**（核心页）：新建/导入任务、勾选批量执行、看实时进度条、双击播放成品、
  审片标「可用/不可用」、打标签、批量归档。支持筛选、字段管理、查找替换。
- **产品中心**：所有素材按「产品 → 品名 → 参考图/视频/音频」树状管理；建任务时按品名
  **自动带上登记的参考图**，不用每次手动传。也能建 KOL 形象。
- **线路负载（📡）**：看每条云端线路的实时情况——并发上限、正在跑几条、剩余槽位、
  健康状态（🟢在线/🟡能应答/🔴连不上）。
- **爆款拆解（🔥）**：粘贴一条爆款视频链接，软件自动拆分镜、提取口播文案，产出画面/文案/
  复刻三类提示词和整体分析，最后给一份 Word 报告。
- **素材工坊**（AIGC 或 基建 任一启用即可见）：
  - **素材库**：把可用成品按「产品/标签」归类成混剪取料的片段；
  - **成品库**：可直接发布的成片卡片管理；
  - **AI 混剪**：把多个片段自动拼成一条新视频。

### 3. 🏗 基建板块（build）
- **批量基建**：面向投放的三级组织结构——**客户 → 执照 → 账户**，把任务/素材按这套组织
  批量铺量，并有执行历史。配合「组织结构」页做权限与数据隔离。

### 4. 🧰 工具中心（tools）
卡片式小工具，每个都能单独配快捷键、固定到侧栏：

| 工具 | 干什么 |
|---|---|
| 💧 视频水印 | 批量打静态/碰撞反弹水印，或统一压制分辨率、码率 |
| 🏷 批量改名 | 按数字/字母/罗马/希腊编号规则批量重命名，先预览再执行 |
| 🖼 封面提取 | 查看视频参数，抽取指定帧生成封面图 |
| ⌨ 批量粘贴录入 | 剪贴板多行文本逐行自动粘贴 |
| 📤 SMB 上传 | 成品视频批量上传到公司共享盘 |
| 🔎 视频溯源 | 溯源码池取码、按规则重命名并入库（需内网 MySQL） |
| 🧲 素材提取 | 粘贴抖音/快手分享链接，提取去水印视频、图集、文案 |
| 🎥 屏幕录制 | 全屏/框选/指定窗口录制，选帧率码率存 MP4 |
| 🎙 语音识别 | 选视频→Whisper 转口播逐字稿，导出 TXT/SRT、可纠错、可烧录字幕 |
| 🔥 爆款拆解 | 见上，AIGC 板块同款能力 |
| 🚀 一键发布 | 选成品与平台账号，一键分发抖音/快手/小红书/视频号 |
| 🗜 素材瘦身 / 🔍 文案查重 | 规划中（压缩参考图、提示词相似度检查） |

> 此外还有**本地文件搜索**：全盘索引后按文件名/内容快速找到本地视频素材。

### 5. 常驻页（不受板块开关影响）
- **📖 新手入门**：软件内置的图文教程，零基础看图学会全部功能（和本指南互补）。
- **⚙️ 设置**：姓名、成品命名规则、内容标签词库、快捷键、账户、输出目录、配置迁移等。
  日常只在这里填姓名、认命名规则、拿/导入配置包即可。
- **👥 组织结构**：三级组织与数据权限维护。
- **🔌 接口管理**（默认隐藏）：只有维护人用口令解锁后才出现，所有接口地址/key 都在那改。

## 二、软件用到了哪些接口，各自干什么

「接口」= 软件联网调用的外部服务。你**几乎不用碰它们**（都内置好了），这里说明白是
为了让你知道「点了某个按钮，背后是谁在干活」。

### 核心接口

| 接口 | 干什么 | 谁在用 | 你要配置吗 |
|---|---|---|---|
| **云端视频生成接口**（多条线路） | 提交提示词→云端 GPU 生成视频→回状态→出成品。多账号**负载均衡 + 故障自动转移**，一条忙/挂自动换下一条 | 任务中心「执行」 | 不用，维护人已内置 |
| **网关服务**（可选） | 商用分发时挡在中间：卡密激活、令牌鉴权、请求转发、限流防刷 | 打包版走网关时 | 不用，地址内置 |
| **机器翻译接口**（火山引擎） | 提示词「中文对照/英文回译」，任务弹窗里用 | 有翻译需求的任务 | 维护人配 key |
| **素材提取接口**（聚客） | 解析抖音/快手分享链接，拿到去水印视频/图集/文案 | 🧲 素材提取 | 同事填 UID/Key，地址内置 |
| **豆包 Vision** | 爆款拆解的**视觉分析**——看懂画面内容 | 🔥 爆款拆解 | 维护人配 api_key |
| **DeepSeek** | 语音识别后的**文案纠错** | 🎙 语音识别 | 维护人配 api_key |
| **发布平台接口** | 把成品分发到 抖音/快手/小红书/视频号 | 🚀 一键发布 | 你授权平台账号 |

### 本地模型（不是联网接口，但也需要就位）
- **Whisper 语音模型**（tiny/base/small/medium 四档）：语音识别转写用，模型在本机跑。
  首次可在「接口管理/配置检查中心」逐档下载（可走国内镜像）。特供/精简版可能不含。

### 关于「接口地址」的一条重要说明
- 接口地址本身就是**访问凭证**，出于安全**默认不摆在界面上**，也不随代码仓库分发。
- 普通同事**只需要填姓名**；要换线路/换机器，用维护人发的**加密线路包 `.aigcline` /
  配置包 `.aigccfg`** 一键导入即可，全程不用手敲任何地址。
- 想知道接口通不通：设置页点「🔌 测试连通性」，看左侧那排灯 🟢 即可。

## 三、五分钟跑通第一个视频

1. **填姓名**（只做一次）：首次打开软件，接口已内置，只填一个用于命名的姓名即可。
2. **建产品**（只做一次）：左侧「🧩 产品中心」→「＋ 新建产品」填品名 → 右键添加参考图。
   提交任务时会按品名自动带上这张参考图。
3. **导入/新建任务**：「🎯 任务中心」→「📁 导入/导出」下载模板填提示词再导入；或「＋ 新建任务」逐条填。
4. **执行**：「🔍 扫描新任务」→ 勾选任务 → 选时长（2~15 秒）和步数（1~50）→「▶ 执行选中」。
5. **看结果**：状态列出现蓝色进度条实时更新，完成后视频自动下载到
   `outputs/日期/`，双击「输出文件」那一格即可播放；右键能快捷定位/复制/标可用不可用。

之后**什么都不用管**：排队、换线、下载、重命名全自动。

## 四、常见问题速查

| 现象 | 说明 / 处理 |
|---|---|
| 提示「至少需要配置一个接口地址」 | 内置地址为空（公司换了服务）才会出现；找维护人要线路包导入 |
| 侧栏灯「服务：检测中…」 | 不是结果，软件启动会逐条真实探活，几秒后换成 🟢/🟡/🔴；点那排灯可手动重测 |
| 日志「acc1 标记为不可用」 | 自动保护，线路连不上会换别的，恢复后自动回 🟢，无需操作 |
| 点了执行没反应 | 确认：提示词非空 + 已勾选 + 接口测试 🟢 |
| 改了时长/步数没生效 | 时长、步数只在**工具栏**那两个下拉里改，表格里那列只是上次留痕 |
| 提交卡很久 | 在等线路空位，几条线全满时新任务会排队，正常；想让一条线多跑就在设置调大并发 |
| 换目录打开后统计归零 | 已修复：数据固定存在 exe 所在目录 / 隐藏配置家，不会再各建空库 |
| 想改姓名 | 删除配置家 `%APPDATA%\AIGC视频助手` 里的 `config.json` 重启，重走向导 |
