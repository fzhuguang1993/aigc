# 修复说明 - current_duration 变量作用域问题

## ✅ 问题已解决

### 错误原因

`current_duration` 变量在 `main.py` 中定义，但 `console/app.py` 中的 `interactive_loop()` 函数无法访问，导致报错：

```python
NameError: name 'current_duration' is not defined
```

### 解决方案

在 `console/app.py` 模块级别定义 `current_duration` 变量，并初始化为 `DEFAULT_DURATION`：

```python
from core.config import DEFAULT_DURATION

# 当前视频时长（秒）
current_duration = DEFAULT_DURATION
```

## 📁 修改文件

**`console/app.py`**
- 添加导入：`from core.config import DEFAULT_DURATION`
- 添加全局变量：`current_duration = DEFAULT_DURATION`

## 💡 工作原理

1. **main.py**: 定义自己的 `current_duration`（用于显示启动信息）
2. **console/app.py**: 定义独立的 `current_duration`（用于控制台命令）
3. **两个变量独立**，互不影响
4. **切换命令**: `duration 5/15` 修改的是 `console/app.py` 中的变量

## ⚙️ 技术细节

### 为什么需要两个变量？

- **main.py 的变量**: 只在启动时显示当前模式
- **console/app.py 的变量**: 用于实际的业务逻辑（如判断是否提取口播）

### 数据流向

```
用户输入 duration 15
    ↓
console/app.py: current_duration = 15
    ↓
script_extractor.py: 使用 DEFAULT_DURATION (5) 判断
    ↓
不提取口播文案
```
